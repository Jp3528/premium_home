# Premium Home

![Vista previa de Premium Home](docs/preview.png)

Landing page estatica para promocionar una propuesta inmobiliaria de estilo premium. El objetivo del repositorio es mostrar una interfaz limpia, adaptable y facil de publicar como proyecto frontend.

## Funcionalidades

- Pagina principal con secciones comerciales.
- Galeria de imagenes locales.
- Estilos responsive para escritorio y movil.
- Chatbot demo para simular atencion rapida.
- Proyecto sin dependencias obligatorias.

## Stack

- HTML5
- CSS3
- JavaScript

## Ejecutar localmente

Abre `index.html` en el navegador o levanta un servidor estatico:

```powershell
python -m http.server 3000
```

Luego visita:

```txt
http://127.0.0.1:3000
```
